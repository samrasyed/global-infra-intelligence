An AI-powered platform that ingests free news sources (RSS/Google News/GDELT-style feeds),
extracts structured intelligence from unstructured articles (countries, companies,
infrastructure category, threat level, investment amounts), and visualizes it across a
dashboard, map, country/company pages, semantic search, and a RAG analyst chatbot.

Built and verified end-to-end in this environment: backend running with seeded demo data,
frontend built and rendering real API data through every core page.

## Stack

- **Backend**: FastAPI, SQLAlchemy, SQLite (dev) / PostgreSQL (prod), APScheduler
- **AI**: spaCy (NER), rule-based threat scoring, sentence-transformers + ChromaDB (vector
  search / RAG), optional Gemini or Ollama for higher-quality summaries and chat
- **Frontend**: Next.js 14 (App Router), TypeScript, Tailwind, Recharts, React-Leaflet
- **No paid APIs required.** Everything runs with zero API keys; Gemini/Ollama are optional
  upgrades for summarization quality, not requirements.

## Quick start (local, no Docker)

### Backend

Use Python 3.11 or newer locally. The backend requirements are pinned to versions
that install cleanly on Python 3.14 without compiling `pydantic-core` from source.

```bash
cd backend
python -m venv venv && source venv/bin/activate
pip install -r requirements.txt
python -m spacy download en_core_web_sm   # optional but recommended
python -m app.seed_data                    # populates demo data so pages aren't empty
python -m uvicorn app.main:app --reload --port 8000
```

On Windows, using the Python launcher:

```powershell
cd backend
py -m venv venv
.\venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m app.seed_data
python -m uvicorn app.main:app --reload --port 8000
```

API docs: http://localhost:8000/docs

### Frontend

```bash
cd frontend
npm install
echo "NEXT_PUBLIC_API_BASE_URL=http://localhost:8000" > .env.local
npm run dev
```

App: http://localhost:3000

### Docker (both services)

```bash
docker compose up --build
```

## Live ingestion

For live-only data, do not run `python -m app.seed_data`. If demo data already exists, remove it:

```bash
python -m app.clear_builtin_data
```

To use live GDELT polling instead of built-in feeds, start the backend with:

```bash
ENABLE_DEFAULT_FEEDS=false GDELT_ENABLED=true ENABLE_SCHEDULER=true INGEST_INTERVAL_MINUTES=60 python -m uvicorn app.main:app --reload --port 8000
```

The scheduler polls the feeds in `app/services/rss_ingestion.py` every hour and runs the
NLP pipeline on new articles. Trigger a cycle manually:

```bash
curl -X POST http://localhost:8000/api/admin/ingest/run
```

Add/manage feeds via `GET/POST /api/admin/feeds`.

## Environment variables

| Variable | Where | Purpose |
|---|---|---|
| `DATABASE_URL` | backend | defaults to SQLite; set to a Postgres URL for prod |
| `ENABLE_SCHEDULER` | backend | `true`/`false`, enables the background ingestion job |
| `INGEST_INTERVAL_MINUTES` | backend | scheduler polling interval; use `5` or `10` for near real-time local polling |
| `ENABLE_DEFAULT_FEEDS` | backend | `true`/`false`, auto-adds the built-in RSS feeds when enabled |
| `GDELT_ENABLED` | backend | `true`/`false`, enables near-real-time GDELT DOC API polling |
| `GDELT_QUERY` | backend | keyword query used for GDELT article search |
| `GDELT_LOOKBACK_MINUTES` | backend | recent time window for GDELT polling; minimum 15 minutes |
| `GDELT_MAX_RECORDS` | backend | max GDELT articles per poll, capped at 250 |
| `NEWSDATA_ENABLED` | backend | `true`/`false`, enables NewsData.io Latest API polling |
| `NEWSDATA_API_KEY` | backend | free NewsData.io API key |
| `NEWSDATA_QUERY` | backend | keyword query for NewsData.io; keep short on the free plan |
| `NEWSDATA_LANGUAGE` | backend | language filter, defaults to `en` |
| `NEWSDATA_TIMEFRAME` | backend | latest-news window in hours, defaults to `24` |
| `NEWSDATA_COUNTRY` | backend | optional country filter like `us`, `gb`, `in` |

| `CORS_ORIGINS` | backend | comma-separated allowed origins |
| `GEMINI_API_KEY` | backend | optional, upgrades summarization + chat |
| `OLLAMA_HOST` | backend | optional, e.g. `http://localhost:11434`, local LLM alternative |
| `NEXT_PUBLIC_API_BASE_URL` | frontend | backend URL, defaults to `http://localhost:8000` |
